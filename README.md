# Customer Churn Prediction

This project uses Machine Learning to predict whether a customer is likely to churn based on customer-related information.

### Project Overview

The dataset is analyzed and preprocessed to identify patterns and factors associated with customer churn. Machine Learning techniques are then applied to build a predictive model that classifies customers into **Churn** or **Not Churn**.

### Key Steps

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature selection and preparation
* Data visualization
* Model training and evaluation
* Customer churn prediction

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* google colab

### Objective

The main objective is to understand customer behavior and develop a Machine Learning model that can help identify customers who may be at risk of leaving.

This project demonstrates practical experience in **Data Analysis, Data Preprocessing, Visualization, and Machine Learning**.
